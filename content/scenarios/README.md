# Escenarios

Pendiente de añadir guiones ejecutables. Crear un escenario por ataque del catálogo con: id, requesterRole, attackId, legitimateTask, defenseConfigurations, expectedOutcomes, exposureRules y maxTurns. Definir resultados antes/después y limitaciones. Para exposición parcial, enumerar los fragmentos que cuentan y cómo se acumulan. No aceptar combinaciones sin resultado definido en modo simulado.
